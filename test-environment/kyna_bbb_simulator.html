Đây là môi trường giả lập y hệt giao diện lớp học thật của Kyna. Bạn có thể dùng trang này để quay video hướng dẫn cho các giáo viên khác.

Hướng dẫn quay video:

  1. Đảm bảo đã cài Extension Kyna và BẬT quyền "Allow access to file URLs".
  2. Click icon Extension góc phải trên cùng để mở Bảng điều khiển.
  3. Chọn Game và ấn Start Game (Khung game sẽ hiện đè lên bảng trắng này).
  4. Sử dụng bảng 🎮 Kyna Student Simulator bên dưới để giả làm học sinh chat.
